NeuroAgent

The auditable agent for neuroscience research. 为神经科学研究而生，能长流程自主运行、全程可审计的智能体。

NeuroAgent executes research workflows as staged, durable pipelines. Every tool call, gate decision, and artifact is recorded and can be inspected, resumed, rolled back, or replayed. NeuroAgent 将科研工作流执行为阶段化、可持久化的流水线。每一次工具调用、每一项门控决策、每一份产物均有记录，并可检查、恢复、回退与复现。

01 · Problem01 · 痛点

Current agents still lack neuroscience background knowledge, autonomous long-workflow research capability, and reproducibility review mechanisms. 现有智能体仍缺少神经科学背景知识、长流程自主科研能力与可重复性审查机制。

GAP · 01短板 · 01 General-purpose agents lack neuroscience domain knowledge, making it difficult to reason about paradigm constraints, brain-signal characteristics, and domain-specific methods for preprocessing, modeling, and statistical analysis. 通用智能体缺少神经科学领域知识，难以准确把握范式约束、脑信号特性，以及预处理、建模与统计分析方法。
GAP · 02短板 · 02 They struggle to autonomously advance long research workflows from literature, hypotheses, and paradigm design to implementation, analysis, and claim review. 它们难以自主推进从文献、假设、范式设计到实现、分析和结论审查的长流程科研任务。
GAP · 03短板 · 03 Tool calls, key decisions, inputs, outputs, and intermediate artifacts lack structured records, making reproducibility review difficult. 工具调用、关键决策、输入输出与中间产物缺少结构化记录，难以接受可重复性审查。
02 · How it works02 · 机制

Domain knowledge, research skills, and governed execution form the research engine. 领域知识、科研技能与受控运行共同构成科研引擎。

NeuroAgent combines neuroscience knowledge, research skills, runtime orchestration, and durable state in one system. It can answer lightweight questions directly or execute selected stages for complex work, while keeping the full run inspectable and replayable. NeuroAgent 将领域知识、科研技能、运行编排与持久化状态组合在同一系统中；它既可直接回答轻量问题，也可按任务需要执行指定阶段，并保留完整运行的检查、恢复与回放能力。

01

Neuroscience knowledge and skills神经科学知识与技能

Paper-distilled knowledge and bundled skills support literature work, brain-data intake, preprocessing, modeling strategy, analysis, writing, and review. 由论文蒸馏的领域知识与内置技能覆盖文献、脑数据审计、预处理、建模策略、结果分析、写作与审查。

02

Adaptive execution modes自适应运行模式

The same interface supports direct answers, user-selected stages, and full staged execution, so lightweight questions and long autonomous tasks do not require separate tools. 同一界面支持直接回答、用户选择阶段执行与完整阶段化执行，轻量问题和长流程任务不需要切换工具。

03

Local governed execution本地受控执行

Runs execute locally with OpenAI-compatible or Anthropic-compatible providers, explicit permission contracts, and sandbox-aware tool behavior. 运行在本地执行，支持 OpenAI 或 Anthropic 兼容 provider，并通过显式权限契约与沙箱感知工具行为控制风险。

04

Durable, auditable runs持久化与可追溯

Sessions, stage artifacts, transcripts, checkpoints, manifests, and final packages are persisted for inspection, resume, rollback, and replay. Session、阶段产物、交互记录、checkpoint、manifest 与最终产物包均会持久化，用于检查、恢复、回退与回放。

03 · Supported neuroscience tasks03 · 支持的神经科学任务

From paradigm design to neural encoding and neural decoding. 覆盖范式设计、神经编码与神经解码。

1

Paradigm design范式设计

NeuroAgent can help specify task structure, stimuli, events, labels, subject/session layout, split protocol, and leakage boundaries before data processing begins. NeuroAgent 可辅助定义任务结构、刺激、事件、标签、被试/会话层级、数据划分协议与泄漏边界，在处理数据之前固定实验范式。

2

Neural encoding神经编码

Encoding workflows can connect stimuli, behavior, representations, and neural responses, then keep preprocessing, feature construction, model fitting, and result interpretation in one staged record. 神经编码流程可连接刺激、行为、表征与神经响应，并将预处理、特征构建、模型拟合与结果解释保存在同一阶段化记录中。

3

Neural decoding神经解码

Neural decoding workflows cover target definition, preprocessing, model selection, training, evaluation, analysis, and claim review for EEG, sEEG, ECoG, and related brain-signal tasks. 神经解码流程覆盖目标定义、预处理、模型选择、训练、评估、分析与结论审查，适用于 EEG、sEEG、ECoG 等脑信号任务。

05 · Quick start05 · 上手

From installation to a staged run. 从安装到一次阶段化运行。

01Install the release package.安装发行包。
curl -fsSL https://github.com/yzz673/independent-neuro-agent/releases/download/neuro-agent-v0.1.0/install.sh | bash -s -- --release neuro-agent-v0.1.0 --yes
02Configure an OpenAI-compatible or Anthropic-compatible LLM provider.配置 OpenAI 或 Anthropic 兼容的 LLM 服务商。
neuro-agent setup && neuro-agent doctor
03Run the bundled BCI demonstration to observe a complete staged pipeline.运行随附的 BCI 公开示例，观察一条完整的阶段流水线。
neuro-agent run --task ~/.neuro-agent/tasks/public_bci_demo.yaml
04Point the agent at your own dataset. When required information is missing, it will request clarification before proceeding.将智能体指向你自己的数据集。缺少必要信息时，它会先请求澄清，再继续执行。

06 · Boundaries06 · 边界

What NeuroAgent is not. NeuroAgent 不是什么。

01✕It is not a lightweight chat interface; for casual question answering, a chatbot is the more suitable tool.它不是轻量级对话界面；若只需要日常问答，聊天机器人是更合适的工具。
02✕It is not a one-click analyzer that works across every dataset and environment without configuration; each run still needs explicit data, compute, and permission boundaries.它不是无需配置即可适配所有数据和环境的一键分析工具；每次运行仍需明确数据、计算环境与权限边界。
03✕It does not replace scientific judgment. It makes research runs auditable; interpretation remains the researcher's responsibility.它不能替代科学判断。它让科研运行可审计；解释与判断仍是研究者的责任。
07 · FAQ07 · 常见问题

Frequently asked questions.常见问题。

Is NeuroAgent a model?NeuroAgent 是模型吗？
No. It is an agent runtime; users supply their own LLM provider.不是。它是智能体运行时，模型由用户自己的服务商提供。
Does it require a GPU cluster?需要 GPU 集群吗？
No. It is local-first; compute-intensive steps run as tools on the user's own machines.不需要。NeuroAgent 本地优先；计算密集型步骤作为工具在用户自己的机器上执行。
What happens when a run is interrupted?运行中断了怎么办？
It can be resumed from the most recent checkpoint, rolled back to an earlier stage, or replayed in full.可从最近的检查点恢复、回退到更早的阶段，或完整复现该次运行。
Can it run unattended?能无人值守吗？
Yes. In dont_ask permission mode, actions that would normally require approval are denied instead of interrupting the user.可以。在 dont_ask 权限模式下，需要确认的操作会被直接拒绝，不会中断执行等待用户。
Is it restricted to neuroscience?只能用于神经科学吗？
No. The runtime is general-purpose; the bundled task families and demonstrations focus on neuroscience research.不是。运行时是通用的；随仓库发布的任务族与示例聚焦于神经科学研究。
