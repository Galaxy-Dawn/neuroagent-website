What to know before you start.使用前，你可能想确认这些问题。

How do I get started?我该如何开始？
Install the release package, run neuro-agent setup to configure your model provider, then use neuro-agent doctor to verify the environment. You can start with the bundled public example before using your own project.先安装发行包，运行 neuro-agent setup 配置模型服务，再用 neuro-agent doctor 检查环境。建议先运行随附的公开示例，再接入自己的研究项目。
Can I use my own model or API provider?可以使用我自己的模型或 API 服务吗？
Yes. Setup currently supports OpenAI, OpenAI-compatible gateways, and Kimi Code through its Anthropic-compatible interface. You provide the endpoint, API key, and exact model ID.可以。当前配置流程支持 OpenAI、OpenAI 兼容接口，以及通过 Anthropic 兼容接口接入 Kimi Code。服务地址、API key 和模型 ID 均由你提供。
Does my research data leave my machine?我的研究数据会离开本机吗？
Runs, tools, checkpoints, and artifacts are managed locally by default. Content included in model requests is sent to the API provider you configure, and remote tools require the corresponding access permission. Review your provider and permission settings before using sensitive data.运行记录、工具、检查点和研究产物默认在本地管理。发送给模型的上下文会进入你配置的 API 服务；远程工具也必须获得相应权限。处理敏感数据前，请先确认服务商和权限配置。
What kinds of research tasks can it handle?它适合处理哪些科研任务？
The runtime is designed for staged scientific work such as research design, data inspection, computational experiments, result analysis, review, and artifact preparation. Available capabilities still depend on the tools, data, compute environment, and domain resources you configure.它适合研究设计、数据检查、计算实验、结果分析、成果审查和产物整理等阶段化任务。实际能够完成什么，仍取决于你提供的工具、数据、计算环境和领域资源。
What if a run is interrupted or needs revision?运行中断或结果需要修改怎么办？
You can inspect the saved run, resume from its checkpoint, roll back to an earlier stage, or replay from a selected stage. The original run records remain available for comparison and review.你可以检查已保存的运行，从检查点继续，回退到更早阶段，或从指定阶段重新运行。原有运行记录仍会保留，便于比较和审查。
Need help or want to share feedback?需要帮助或进行反馈？
Open an issue on GitHub Issues. Include the command you ran, the visible error, and relevant environment information, but remove API keys and sensitive research data first.请前往 GitHub Issues。建议附上执行命令、可见错误和相关环境信息；提交前请删除 API key 和敏感研究数据。
